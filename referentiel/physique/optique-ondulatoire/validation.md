# Validation : optique ondulatoire (oo, 52 cartes)

Sources lues : PROGRAMME-PC-MP-2021, ISM-PC-O-1 à O-4, PC-CHAMPOLLION-OPTIQUE-CH1 et CH2 (Cours 2025). Le contenu n'a pas été comparé au BO.

Bilan des notes d'origine traitées (53 : 38 + 12 mp + 3 phys_00) (phys_14 : 38 ; mp_optique-p : 13 dont 1 dans og ; phys_00 : diffraction, OPPH, deux ondes) :
- toutes réécrites ou fusionnées ; 5 corrigées (notes 607, 653, 657, 637, 641) ; nouvelles cartes : 12.
- Écartées (hors périmètre, motif) : 1790858881801 (signal sinusoïdal, traitement du signal), 1790858881811 (effet Doppler, ondes).
- 1770158565916 (« Fonctionnement d'une lentille ») traitée dans optique-geometrique.

Erreurs trouvées dans les cartes d'origine :
- Note 657 (trous d'Young) : S1,2=(0,∓a/2,0) puis calcul en x ; S2M²−S1M²=2ax a un signe incorrect avec cette position. Convention refaite.
- Note 607 : « lampe spectrale ~mm » ; ISM : 3 cm (basse pression), 0,3 mm (haute pression).
- Note 653 : HeNe Δλ~10⁻³ nm correspond au multimode (1 pm) ; monomode 10⁻³ pm.
- Note 641 : cannelures en λ=δ/p : il faut p demi-entier pour les minima.
- Note mp « doublet » : λ=596 nm pour le sodium ; valeur réelle ≈589 nm (589,0 et 589,6).
- Note 637 : axe de décalage de la source ambigu (y_S ou x_S).

Divergences entre sources : temps de réponse d'une photodiode (1 µs ISM, 1 ns Champollion) ; π au passage par un point de convergence (ISM seulement) ; largeur de la lumière blanche 300 à 400 nm ; indexation des anneaux (ISM n+ε, ici k+ε avec k=0 central) ; critères de brouillage (1/2 centre-bord, 1 bord-bord) équivalents.

Exigibilité : réseaux (relation fondamentale, demi-largeur 2π/N), Young, Michelson lame d'air, coin d'air (expérimental, δ admise), cohérence : confirmé dans le programme. Pouvoir de résolution, diffraction (ouverture angulaire, taille du champ) : hors programme explicite. Fentes d'Young : expérimental seulement.

Vérifications par calcul : DL de δ, S2M²−S1M², δ=2e cosi, i_k, Δe=λ²/(2Δλ)=0,29 mm, e1=0,14 mm, ℓs=0,25 mm, α=2,7·10⁻⁷ rad, D_min, somme géométrique du réseau.
Manque : cohérence Fabry-Pérot (hors programme), fiche scannée de Champollion non lue, Ch3 Michelson de Champollion téléchargé mais non lu (seules deux sources Champollion enregistrées).
